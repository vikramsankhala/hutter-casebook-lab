# Hutter Casebook Lab

Companion repository to *The Hutter Prize Casebook* (Solinexta AI Press, 2026). Twelve small, deterministic experiments that test ideas for compressing text, each with a baseline and a capacity-matched noise control.

All results are on a synthetic corpus, the River Archive II, generated by `hcl/corpus.py`. Set `HCL_ENWIK=/path/to/enwik8` to run on real data; the repository does not download it. Numbers on the synthetic corpus are not predictions for Wikipedia.

## The books

The casebook and the instructor handbook are in [`books/`](books/).

## Run

```
pip install -r requirements.txt
python run_all.py                       # about one minute, deterministic
python scoreboard.py                    # net-of-control table
python -m unittest discover -s tests -v # 18 tests
```

## Caveats

Synthetic corpus; static surrogate costs in E03; the recurrence estimator in E12 is biased and approximate; E09 and E10 are conceptual demonstrations on constructed sources.
